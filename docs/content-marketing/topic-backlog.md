# 内容营销选题清单（获客指南 Backlog）

面向出海广告主 / 独立站卖家 / 代运营的**搜索型内容资产**排期清单，服务于 `/guides` 板块的持续产出。

## 怎么用这份清单

- **主题簇（cluster）优先**：同簇文章互相内链，形成主题权威，比零散写单篇更利于排名。
- **优先级**：`P0` 先写（高意向 / 高转化 / 差异化 / 易内链）· `P1` 次批 · `P2` 长尾补充。
- **意图**：`信息` 型拉新认知 · `商业` 型接近决策、转化最高。
- **承接**：每篇正文与结尾 CTA 应内链到对应产品页，形成「内容 → 产品」漏斗。
- **落地**：写新文只改 `app/guides/_content/articles/*.ts`（结构化块 p/list/steps/table/callout/faq），并按范式补**经核实的官方参考资料**；不改渲染组件。
- **数据驱动**：挂上 Google Search Console 后，结合真实曝光/点击数据调整选题与内链。

先打**差异化 + 高转化 + 易内链**：

1. 海外落地页工具选型指南（商业意图，直接接定价）

3. 广告账户被封 / 限流自查
4. TikTok 落地页防拒审（补齐 FB / TikTok / Google 三平台矩阵）
5. 高转化落地页结构拆解
6. 美妆出海获客打法（内链 skincare 模板，跑通「行业文 → 模板页」漏斗）

**排序逻辑**：先覆盖差异化（反同质化 / 合规）与商业意图词（工具选型）——前者竞争对手写不了、后者离转化最近；行业文与技术文作为持续产能补充。

## 提醒

- 内容营销是马拉松：3–6 个月见自然流量起色，需**持续产出**（建议每月 2–4 篇），停更即停长。
- 每篇务必附**经核实的官方参考资料**（一手来源，提升 E-E-A-T 与被 AI 摘要引用的概率）。
- 相关基建与已发布文章见 `app/guides/`。
