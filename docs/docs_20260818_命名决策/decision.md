# 品牌更名决策：Zap Bridge → Urgizat

日期：2026-08-18　　状态：已定案，`urgizat.com` 已注册

## 为什么要改

Google 对 "ZapBridge" 生成消歧义式 AI 概览，把四个不同产品并列：WooCommerce webhook 插件、本产品、一款短信备份 App、一个 Go 日志库。同时 WooCommerce 市场存在名为 "ZapBridge - Zapier Integration" 的插件。品牌词无法归属到本产品，与 Zapier 的字面相似进一步稀释识别度。

GSC 三个月数据佐证品牌信号接近于零：2 次点击、47 次展现、平均排名 35.7。

## 选定的名字

**Urgizat**（`urgizat.com`）

- 读音：UR-ji-zat `/ˈɜːrdʒɪzæt/`
- 构词：`urge`（促动）+ `-ization` 词干截断
- 对外口径统一为「promote action / 促成行动」，**不使用「制造紧迫感」这一说法**——紧迫感战术紧邻广告平台管控的暗黑模式地带，与本产品的生成页合规红线冲突

## 判据与验证结果

## 淘汰的候选与理由

`pagruct` 是最后的对手，语义为 pagina（页）+ struct（构建）。淘汰理由是**语义指向过窄**：产品定位已在首页拓宽那轮主动从机制侧搬到结果侧（Hero 改为「把访客变成能打通的联系方式」），且产品早已不止页面构建（留资链路、归因、自检器、反同质化风控、线索跟进）。名字比文案难改，文案脱节已修过三轮。此外 `pag-` 源自拉丁语，英语母语者不会自动解码，「一看就懂」的收益是理论的，语义收窄的代价却是实际的。

其余淘汰项及理由：

- `irciany` / `ichexte` —— 存在精确同名实体（No Man's Sky Wiki 条目；ICHEXTE 国际会议缩写）
- `oulcial` / `unemput` —— 撞 official / unemployment 等超高频词，品牌搜索长期被纠正走
- `wilaxid` —— 含真实药品牌 AXID
- `tupsomy` —— 撞 `-somy` 染色体疾病后缀
- `judabse` —— Judas 负面宗教联想
- `giciock` —— 硬改写至活跃产品 GiCheck
- `whoudge` / `rerpois` —— 拼读歧义不可接受

## 方法论上修正过两次的判据

1. **纠正检测有三种措辞**，最初只覆盖两种，漏掉「These are results for X / Did you mean: a b c d」。修正后判断从「匹配横幅」改为**读 SERP 标题**。
2. **纠正触发 ≠ 有人占位**。Google 对任何未被索引的字符串都会去猜最近的已知词，这恰恰证明该字符串是空位。真正的否决条件是**存在精确同名实体**。Mailchimp 在 2002 年同样会被纠正。

## 已知的遗留风险

- **读音**：`g + i` 在英语中软硬不定（give vs giant）。`urg-` 词素（urge/urgent/urgency）全部读软音，会强力引导至 UR-ji-zat，但残留争议存在，先例是 GIF / Giphy。
- **构词截断**：`-izat` 天然期待 `-ion` 结尾，可能出现 urgization / urgizate 的错拼。
- **商标混淆可能性分析未做**——TMview 只验证了字面包含，法律判据需律师意见。
- **品牌信号从零开始**：Google 切换到本实体需要索引 + 实体信号 + 品牌搜索量积累，通常数月。
